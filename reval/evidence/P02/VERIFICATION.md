# شاهد بررسی P02

- تاریخ: 2026-11-19
- مخزن اجرایی: `../reval-app`، شاخهٔ `main`، کامیت `e1f12ab`
- محیط اجرا: Windows 10 Enterprise LTSC، Node.js 22.19.0، npm 10.9.3 و MongoDB 8.0.13. اجرای یک replica set آزمایشی روی loopback، با پورت و مسیر دادهٔ موقت. سرویس‌های آزمون پس از پایان متوقف شدند.
- دادهٔ ساختگی: نشانگر migration، یک سند seed و دو رکورد آزمون تراکنش.

| بررسی | انتظار | نتیجه |
|---|---|---|
