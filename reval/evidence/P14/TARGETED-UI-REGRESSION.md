# رگرسیون تکمیلی رابط برای G7

تاریخ 2026-11-20 · نسخهٔ آزمون 0b91ea3 · Chrome روی Windows و MongoDB replica set آزمایشی

آزمون مرورگر با API واقعی روی پایگاه آزمایشی جدا اجرا شد. برای آزمون صفحه‌بندی ۱۴ محموله، ۱۴ تأمین‌کننده و ۱۴ حساب غیرفعال مصنوعی ساخته شدند. آزمون با حساب دارای نشست و یک مرورگر بدون نشست اجرا شد. چاپ با فراخوانی پنجرهٔ مرورگر بررسی شد.

فرم ایجاد نقش نیز باز شد. چون فرم به‌صورت داخل صفحه نمایش داده می‌شود، ردیف پنجرهٔ مرجع PASS نشده است.
