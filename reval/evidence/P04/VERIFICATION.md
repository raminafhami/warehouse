# شاهد بررسی P04

تاریخ 2026-11-19. مخزن مستقل `../reval-app`، کامیت `86919fd`. محیط Windows، Node.js 22، MongoDB 8 replica set ایزوله و Chrome. همهٔ مواد، مدل‌ها و حساب‌ها آزمایشی‌اند.

| آزمون | انتظار و نتیجه |
|---|---|
| TEST-P04-CATALOG | PASS. ثبت واحد، نوع قطعه، تأمین‌کننده، SKU، رنگ، مدل، شعبه، خط، ایستگاه، تست، انبار و موقعیت. کد کالای تکراری با تفاوت حروف رد شد. رنگ اشتباه و انبار یا قالب موقعیت نامعتبر پیام مرتبط داشتند. کد یکسان خط در دو شعبه مستقل ثبت شد. |
| TEST-P04-VERSION | PASS. انتشار هم‌زمان نسخه‌های BOM شماره‌های متوالی تولید کرد. نسخهٔ بدون تغییر رد شد. پس از انتشار BOM جدید و غیرفعال‌سازی قطعهٔ قدیمی، نسخهٔ اولیه با همان شناسه و همان قلم و مقدار بازیابی شد. اصلاح سقف تست مجدد ایستگاه، snapshot مسیر قبلی را تغییر نداد. |
| TEST-P04-PROTECTION | PASS. غیرفعال‌سازی قطعهٔ مصرف‌شده در BOM جاری و نوع قطعهٔ در حال استفاده رد شد. مسیر حذف وجود ندارد. کاربر شاخهٔ دیگر رکورد خط خارج از محدوده، ایجاد SKU و خروجی بی‌مجوز را دریافت نکرد. نسبت شعبه و خط در تخصیص محدوده بررسی شد. |
| TEST-P04-BARCODE | PASS. API بارکد PNG برای موقعیت ساخت. Chrome تصویر بارکد Code 128 مدل را بارگذاری کرد. |
| TEST-P04-CHROME | PASS. صفحهٔ اطلاعات پایه باز شد، رنگ و مدل از فرم ثبت شدند، رنگ از دادهٔ موجود انتخاب شد و تاریخچهٔ نسخه‌ها از صفحهٔ مدل قابل بازکردن بود. مسیر دو نقش P03 دوباره پاس شد. |
| TEST-P04-CHECKS | PASS. lint، فرمت، typecheck، build، تست‌های پایه و مجموعهٔ یکپارچه‌سازی. |

حفظ سفارش قدیمی در این مرحله با بازیابی snapshot از شناسهٔ نسخه بررسی شد. گردش واقعی سفارش تولید در P08 پیاده می‌شود. تطابق پیکسلی، خروجی چاپ واقعی و اسکن با دستگاه فیزیکی بررسی نشده‌اند. وضعیت Docker از P02 جداگانه باز است.
