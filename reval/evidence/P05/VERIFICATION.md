# شاهد بررسی P05

تاریخ 2026-11-19. مخزن اجرایی `../reval-app`، کامیت `3291a3f`. محیط Windows، Node.js 22، MongoDB 8 replica set ایزوله و Chrome. فایل، محموله، قطعه و حساب‌ها همگی آزمایشی‌اند.

| آزمون | انتظار و نتیجه |
|---|---|
| TEST-P05-SCOPE | PASS. اپراتور انبار دیگر محموله و بارنامهٔ خارج از محدوده‌اش را نتوانست بگیرد. خروجی بدون مجوز رد شد. اپراتور همان انبار رسید را دید ولی اجازهٔ تأیید نداشت. |
| TEST-P05-FILE | PASS. فایل بیش از ۱٫۵ مگابایت، محتوای نامعتبر و نوع اعلامی ناسازگار رد شدند. فایل PNG معتبر باینری ذخیره و با همان بایت‌ها به‌صورت پیوست دریافت شد. |
| TEST-P05-SCAN | PASS. بارکد تکراری، پالت محمولهٔ دیگر، قطعهٔ تأمین‌کنندهٔ دیگر و تعداد صفر رد شدند. کارتن اسکن‌شده قبل از دریافت قابل حذف بود و کارتن دریافت‌شده قابل حذف نبود. |
| TEST-P05-RECEIPT | PASS. دریافت یک محمولهٔ کامل تأیید شد. برای کسری و قرنطینه شرح خواسته شد. ارسال هم‌زمان دوبار با همان کلید دقیقاً یک رسید و یک اثر برای هر کارتن داشت. کلید تکراری با ورودی یا محمولهٔ دیگر رد شد. نسخهٔ قدیمی و دریافت بدون کارتن نیز رد شدند. |
| TEST-P05-BALANCE | PASS. ۵ واحد سالم به حساب دریافت و ۲ واحد آسیب‌دیده به حساب قرنطینه رفت. رسید تکمیلی کسری را کاهش داد. بستن مغایرت ماندهٔ قرنطینه را تغییر نداد. |
| TEST-P05-BROWSER | PASS. ثبت محموله، پیوست، اسکن با Enter و پیش‌نمایش بارکد کارتن اجرا شد. پس از ثبت رسید در سرور، پاسخ اول عمداً قطع شد. تلاش مجدد با همان کلید پاسخ موفق گرفت. Refresh و یک نشست مستقل Chrome رسید، کارتن و فایل را دیدند. |
| TEST-P05-CHECKS | PASS. lint، فرمت، typecheck، build، ۲ تست پایه و ۴ مجموعهٔ یکپارچه‌سازی. |

لیبل در مرورگر از Code 128 تولید می‌شود. تطابق دقیق قالب چاپ، خروجی PDF گزارش و خواندن لیبل با تجهیزات فیزیکی در این اجرا بررسی نشده‌اند. جانمایی در P06 آزموده می‌شود. اجرای Docker از P02 باز است.
