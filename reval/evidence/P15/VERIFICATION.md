آرشیو سرد آزمایشی ۳۱۶۴۰۷ بایت بود. زمان گرفتن آرشیو ۶۷۲ میلی‌ثانیه و بازیابی تا پایان اعتبارسنجی ۱۷۷۴ میلی‌ثانیه بود. آزمون بازگشت نسخه قبلی API روی همان نمونه حدود ۶۶۰ میلی‌ثانیه طول کشید. این اعداد برای دادهٔ مصنوعی روی یک ماشین هستند و هدف‌های RPO/RTO در D08 را تعیین نمی‌کنند.

دانلود MongoDB Database Tools از میزبان رسمی با HTTP 403 منطقه‌ای رد شد. تمرین بازیابی سرد با MongoDB بومی انجام شد. آزمون mongodump/mongorestore، TLS روی دامنهٔ واقعی، digest imageها، هشدارهای محیط و پایلوت در انتظار محیط و دسترسی مصوب‌اند.
