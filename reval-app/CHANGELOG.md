# REVAL Changelog

## آمادهٔ بررسی برای انتشار

مبنای اجرایی بسته کامیت 2824570 است. این بخش پیش‌نویس تغییرات برای بررسی پذیرش است. شمارهٔ انتشار و digest تصویرها پس از تأیید G9 ثبت می‌شوند.

- ورود مستقل، نقش‌ها و محدوده‌های شعبه، انبار، خط و ایستگاه، با Audit سمت سرور
- اطلاعات پایه، BOM و مسیر تولید نسخه‌دار، محموله و ذخیرهٔ بارنامه، جانمایی، رزرو، تحویل مواد و تطبیق دفتر
- IMEI و دستور تولید، آماده‌سازی و تحویل سبد، مونتاژ، کیفیت مرحله‌ای، تعویض و مرجوعی
- کیفیت نهایی، ارجاع برای اصلاح، اسکن تطبیقی بسته‌بندی، کارتن ۹تایی و انبار محصول
- رهگیری IMEI، قطعه، بچ و محموله، داشبورد عملیاتی و خروجی CSV و PDF مرورگر
- بازیابی سرد آزمایشی، آزمون بازگشت API قبلی، حفظ کلید تکرار در قطع پاسخ و الزام HTTPS برای staging
- پیش‌نویس OpenAPI برای ۲۴ عملیات و آزمون قرارداد با fixture آفلاین روال

توزیع به فروشنده طبق D01 خارج از دامنهٔ تحویل اول است. اتصال رسمی همتا، کار با تجهیزات محل مشتری، ظرفیت مصوب، اجرای Docker در مقصد و پذیرش پایلوت به شواهد تکمیلی وابسته‌اند.
