# تطبیق رابط REVAL با مرجع

مرجع `../reval/reference/REVAL.html` و فهرست تعاملات P00 مبنای این بررسی‌اند. تصاویر برنامه با سرور محلی و داده مصنوعیِ پایدار ثبت می‌شوند. در مقایسه، تاریخ، مقادیر، نام کاربر و داده ورودی دو محیط متفاوت‌اند.

| مسیر | تطبیق انجام‌شده | اختلاف باز |
|---|---|---|
| `/login` | نشان‌ها، پس‌زمینه، شیشه، انتخاب نقش نمایشی، نشان و دکمه نمایش رمز | داده ورودی نقش، وضعیت تمرکز و اختلاف جزئی پویانمایی |
| `/` | تصویر خط، نقاط تعاملی، فیلتر خط، چهار KPI، هشدارها و نمودارهای زنده | جزئیات انواع نمودار، محور، بازه شاخص و بعضی رنگ‌ها |
| `/trace` | کارت جست‌وجو، میان‌برها، حالت خالی، اسکن آزمایشی و نتیجه API | نمایش تصویری کامل زنجیره و نمونه‌های همه میان‌برهای مرجع |
| `/shipments` | تیتر، فیلترهای وضعیت، جدول محموله و پیش‌نمایش PDF | چیدمان دقیق همه ستون‌ها و پنجره‌های پالت و کارتن |
| `/inventory` | نوار وضعیت، تب‌ها، نقشه گروه‌بندی‌شده و اشغال واقعی موقعیت | شکل نقشه برای تمام انبارها، ترتیب بعضی تب‌ها و کنترل‌های گردش کالا |
| `/handover` | فهرست و جزئیات هم‌زمان، وضعیت، اسکن و کارت موجودی | جزئیات ردیف‌ها، کارت‌های تحویل و حالات اسکن |
| `/imei` | عنوان، نوار آمار، تب‌ها و داده مصنوعی معتبر | چینش دقیق وضعیت‌های همتا و فرم‌های ورود فایل |
| `/basket` | انتخاب خط، پرونده سبد داخل صفحه، نوار تیره و فهرست سبدها | جای‌گذاری جزئیات برچسب‌ها، کارت‌های قطعه و چرخه اسکن |
| `/assembly` | مراحل ایستگاه، نوار تحویل سبد، صف و نمای عملیات هم‌زمان | نمایش دقیق چک‌لیست، ترتیب کارت‌ها و حالات عملیاتی همه ایستگاه‌ها |
| `/final-qc` | نوار وضعیت، دو تب، صف و فرم پرونده هم‌زمان | تطبیق جزئی فرم آزمون، بسته‌بندی و ریزنقش‌ها |
| `/stage-qc` | آمار، نتایج، ارجاع‌های فنی، تعویض، نرخ و صف آزمون | فیلترهای نمای مرجع و بعضی ریزحالت‌های آزمون مجدد |
| `/defects` | سه تب و نوار آمار و داده پرونده و مرجوعی | ظاهر جزئی پذیرش قطعه، پرونده و سند تأمین‌کننده |
| `/finished` | نوار آمار، تب‌ها، کارتن باز و جزئیات کارتن هم‌زمان | صف مستقل جعبه‌های آماده، جزئیات نقشه و گردش توزیع |
| `/reports` | چهار نمودار زنده، انتخاب گزارش، فیلتر و پیش‌نمایش PDF | نمودار مقایسه‌ای کنار خط، جزئیات قالب چاپ و بعضی گزارش‌های سند جامع |
| `/master` | تب‌ها، فهرست مدل و BOM و مسیر تولید در دو ستون | جزئیات همه ویراستارها و تب‌های اطلاعات پایه |
| `/users` | تب کاربر و نقش، تراشه‌های خط، آواتار و کنترل‌های نقش | چیدمان دقیق ویرایشگر و ماتریس همه نقش‌های مرجع |
| `/audit` | نوار آمار، فیلتر بخش و نتیجه، جدول و PDF | جزئیات فیلتر تاریخ و عامل و حالت نمایش قبل و بعد |

زیرمسیرهای عملیاتی از اجزای مشترک و موضوع بصری جدید استفاده می‌کنند. تطبیق تمام زیرمسیرها، تب‌ها، خطاها، نقش‌ها، چاپ و پنجره‌ها هنوز شرط تحویل نهایی است. [موارد باز](DEVIATIONS.md)

شواهد مرورگر شامل جفت تصاویر ۱۷ مسیر در ابعاد ۱۴۴۰×۹۰۰، ۱۹۲۰×۱۰۸۰ و ۱۰۲۴×۷۶۸ در `../output/reval-ui-parity` است. این مقایسه پوشش نمای اصلی را نشان می‌دهد و معادل تأیید پیکسل‌به‌پیکسل نیست.

## نتیجه بررسی محلی

- ۵۱ جفت تصویر ثبت شد. در مرور مسیرهای اصلی خطای جاوااسکریپت، پاسخ خطای API یا اسکرول افقی در سطح صفحه دیده نشد.
- ۱۱ مسیر جزئیات و صف با داده تازه باز شدند و تصویر هرکدام در پوشه `details` کنار شواهد اصلی ثبت شد.
- در Chrome ورود، نمایش رمز، جست‌وجوی کارتن، انتخاب درخواست و مدل، صف بسته‌بندی، پنجره محموله، منوی تبلت و رد دسترسی اپراتور ایستگاه به کاربران آزموده شدند.
- Chrome از محموله‌های نمونه PDF یک‌صفحه‌ای ساخت. متن PDF شامل بارنامه نمونه است. آزمون دیجیتال چاپ و خواندن Code 128 برای لیبل لجستیک، جعبه و کارتن محصول هم پاس شد.
- Build، Typecheck و Lint و ۱۳ آزمون واحد و یکپارچگی پاس شدند.
- `pixel-diff.json` اختلاف خام رنگ پیکسل‌ها را نگه می‌دارد. هیچ جفتی از تصاویر فعلی با داده متفاوت کاملاً یکسان نیست. این عدد معیار درصد پیاده‌سازی نیست.
